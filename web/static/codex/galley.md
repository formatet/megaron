The **Galley** is the ordinary ship: built of timber, rowed by twenty, the hull that carries your people and your goods across the [[sea|Thalassa]].

| | |
|---|---|
| **Built at** | Shipyard ([[shipyard]]) |
| **Cost** | 30 timber · no silver |
| **Crew** | 20 rowers, drafted from the city |
| **Build time** | 3 game days |
| **Food** | 0.1 per game day in port, 0.2 at sea |
| **Pay** | none |
| **Cargo** | 20 goods of any kind ([[transfers]]) |
| **Troops** | one land unit at a time, any size |
| **Speed** | ordinary |
| **Hull** | 5; repaired with timber |
| **In battle** | 1 die per round, weaker as the hull is damaged |

A galley is what most realms sail first. It can carry a cohort to a new shore and [[colonies|found a colony]] there, take a [[messengers|messenger]] across the water, explore, patrol or run a freight route. It does not fight well; for that, build a [[war-galley]]. For bulk trade, the [[emporos]] carries six times as much.
