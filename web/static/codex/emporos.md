The **Emporos** is the merchant hull: broad, slow, cedar-built, made to carry.

| | |
|---|---|
| **Built at** | Shipyard |
| **Cost** | 16 cedar · no timber, no silver |
| **Crew** | 10 rowers |
| **Build time** | 4 game days |
| **Food** | 0.05 per game day in port, 0.1 at sea |
| **Pay** | none |
| **Cargo** | 200 weight — e.g. 100 grain or 133 fish ([[transfers]]) |
| **Troops** | one land unit at a time |
| **Speed** | slowest ship — 1.4 times a galley's travel time |
| **Hull** | 5; repaired with cedar |
| **In battle** | 1 die per round, like a [[galley]] — it is no warship |

When a shipment is too heavy for a [[galley]], the Emporos takes it; freight picks an Emporos before a galley when both stand in port. It needs cedar, which not every coast has ([[goods]]). See [[units]], [[sea]] and [[trade]].
