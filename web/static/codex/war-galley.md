The **War Galley** is the warship: cedar-built, fifty at the oars, fast and dangerous.

| | |
|---|---|
| **Built at** | Shipyard + Foundry |
| **Cost** | 100 cedar · 30 silver |
| **Crew** | 50 rowers |
| **Build time** | 5 game days |
| **Food** | 0.25 per game day in port, 0.5 at sea |
| **Pay** | 0.25 silver per game day at home, 0.5 at sea ([[silver]]) |
| **Cargo** | no goods |
| **Troops** | one land unit at a time |
| **Speed** | fastest ship — 0.6 of a galley's travel time |
| **Hull** | 5; repaired with cedar |
| **In battle** | 5 dice per round against a [[galley]]'s 1, weaker as the hull is damaged |

Build it when ships must fight or hunt other ships. It carries no cargo, so trade stays with the [[galley]] and the [[emporos]]. See [[units]] and [[battle]].
