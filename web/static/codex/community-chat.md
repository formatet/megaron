Community chat is outside the game, on Matrix. It is optional: questions, bug talk and alpha news. Chat messages do not reach the game world. There is no bridge to [[messengers]], no game commands in Matrix, and important game announcements stay inside the game.

## Your chat account

Your chat account is created after you own your first city. It uses your Wanax name, and stays with your game account across world reseeds. If account creation is pending, check again later.

Click your Wanax name at the top left to open **Account**. Under **Community chat**, the ready account shows your chat ID and homeserver. Press **Get chat password** to set a new password and display it once. Each request replaces the previous chat password. Save it before closing the window; the game does not store it. The `agora_ready` notification opens this same account window, and never carries a password.

Open `agora.formatet.se`, or a Matrix app using the displayed homeserver, and sign in with your chat ID and password. Ask us to invite you to `#megaron-ooc`.

From [[keryx]], use `keryx agora` to check the account and `keryx agora password` to explicitly set and print a new chat password. No world needs to be selected. If Community chat is disabled on the server, no password button is offered.

## Chat rules and privacy

- Be decent. No harassment, no hate, nothing illegal.
- Talk about the game, not other players' real lives.
- Don't post your real name, address, school, health or other private details. Your chat account uses your Wanax name, so other members can see which ruler you play.
- Report a message with the menu next to it in your Matrix app, or write to a moderator. Moderators can read what is reported.

The chat runs on our own hardware in Sweden and is not connected to any other Matrix server. The room is not encrypted, so don't treat it as private. Messages stay until they are deleted. There is no self-service account deletion in the game. Ask a moderator about removing a chat account.

For an in-game problem, use [[report]].
