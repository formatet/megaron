For ordinary game accounts, your chat account is created after you own your first city. It uses your Wanax name, and stays with your game account across world reseeds. If account creation is pending, check again later.

AI playtest accounts are exempt: no community chat account is provided, and no chat password can be requested.

Click your Wanax name at the top left to open [[account|Account]]. Under **Community chat**, the ready account shows your chat ID and homeserver. Press **Get chat password** to set a new password and display it once. Each request replaces the previous chat password. Save it before closing the window; the game does not store it. The `agora_ready` notification opens this same account window, and never carries a password.

Open `agora.formatet.se`, or a Matrix app using the displayed homeserver, and sign in with your chat ID and password. Ask us to invite you to `#megaron-ooc`.

From [[keryx]], use `keryx agora` to check the account and `keryx agora password` to explicitly set and print a new chat password. No world needs to be selected. If Community chat is disabled on the server, no password button is offered.
