A Foundry turns [[copper|copper]] and [[tin|tin]] into bronze.

Build or upgrade it in **City → Buildings → Construct**, or use `keryx build --type foundry`.

| Build time, level 1 | 16 game days |
| Maximum level | 1 |
| Recipe | 9 copper + 1 tin → 1 bronze |
