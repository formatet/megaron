# rise / leave — BILD (Firefox 1:1)

Epitafsidan efter att sista staden fallit. Renderad med serverns egna mallar (`WebHandler.render`, epitaph.html
på grenen `claude/rise`), fotad i Playwright-Firefox efter 9 s av textrullningen.

- `choose-desktop-firefox.png`, `choose-mobile-firefox.png`: dispossessed. *Gather the survivors* / *Leave this world*,
  och en rad om vad det första valet innebär. Knapparna står på en mörk toning nedtill (tvilling till sidans toning
  upptill), så att rullningen passerar bakom dem. Utan den gick förklaringsraden genom rullningstexten och blev oläslig.
- `departed-*-firefox.png`: efter *Leave this world*. Bara utloggning.
