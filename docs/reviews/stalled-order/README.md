# Stalled order content

Contract: a Wanax opening a PassageStalled dispatch for their own order sees which unit and the sealed instruction, including target and mission. Old persisted dispatches are enriched from that same sender-owned envelope on read. Foreign runners and private orders never enter the response. No runner moves, order changes or notification-event reinterpretation. The existing dispatch layout gains text only; web and Keryx show the same summary.

Result on migration194 fresh PostgreSQL: own order summary included on the actual stalled push and enriched for existing archived notice reads; a foreign owner receives no summary. The web escapes the sealed text and Keryx prints it. Targeted Go/JS/vet green. Mutation reversing sender ownership makes the archived-order test fail. Full suite after rebase to current master remains before integration.
