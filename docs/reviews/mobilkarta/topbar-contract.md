# U tillägg — nåbar topprad

Kontrakt före kod, samma codex/mobilkarta från b19a2479.
Blockerar kedjegrinden: 390px-spelaren kan inte nå sök eller hjälp.
Alla tre knappar (☍, ⌕, ?) måste ligga helt inom viewport, vara hit-testbara
och öppna sina befintliga ytor med verkligt tryck. Ingen horisontell scroll.
Kalenderns flexutrymme får krympa; full månad finns kvar i DOM och exakt datum
finns redan i Notifications. Desktop och U:s pekhantering behålls.
Scope CSS topbar och browserbevis; ingen kalendersemantik, mall/server/Keryx.
Röd rect-baslinje först, tre motorer desktop/390, riktiga main.js-bryggor och
UI-kontroller med bootstrap ersatt av explicit HTTP-fixtur. Fysisk CSS-mutation
ska slå ut namngivet rect-prov. Nya Firefox-bilder i topbar-v2/, BILD före merge.
